Project Overview

This project explored how deep learning can be used to understand complex events in soccer video. The main goal was to detect fouls and support card prediction by learning patterns from multi-view match footage.

I worked with CNN-based and Transformer-based models, built the workflow for data preparation and evaluation, and compared different approaches to understand which models performed best on the task.

What I Built

  • Prepared and structured multi-view sports video data for modeling
  • Tested deep learning approaches for event understanding in soccer footage
  • Compared CNN-based and Transformer-based models
  • Evaluated model performance and analyzed strengths and limitations
  • Developed a complete research workflow from data processing to results interpretation
